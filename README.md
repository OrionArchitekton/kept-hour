# Kept Hour

Free calculator: what an hour of your life is worth after tax, commute, and meetings.

Live site: https://orionarchitekton.github.io/kept-hour/

```bash
python3 build.py
```

Static files only. No build step beyond that script. See `DISTRIBUTION.md` for the 30-day traffic plan. Math and defaults are documented on the about page. This is a planning tool, not tax advice.
